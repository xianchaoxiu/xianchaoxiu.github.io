### 什么是研究生
* 本质上, 研究生是学习从事科研的学生
* 研究生不是人才, 优秀的研究生才是人才
* 研究生与本科生的区别
  - 研究生: 体验知识 → 学会创造 → 开展研究 → 提升素养 → 增长能力
  - 本科生: 学习 → 考试 → 60分 → 毕业 → 就业


### 什么是导师
* 导师目前只是合作者, 有可能发展成朋友
* 导师与学生双向选择, 双方都有权解除师生关系
* 导师与学生认识问题的差异
  - 导师: 努力刻苦钻研 → 提高科研能力 → 夯实学术水平 → 毕业
  - 学生: 毕业 → 必要的水平 → 必要的能力 → 必要的努力

 
  
### 应具备的基本素质
* 自驱力强, 身心健康
* 先学做人, 再谈做研究
  - 不要不懂装懂
  - 不要认为别人都是傻瓜
  - 不要认为天上会掉馅饼
  - 不要认为别人都会以你为中心
  - 不要把偶然性的侥幸当做必然性的成功
  - 不要在同一个地方跌倒两次或两次以上
  - 不要把别人的宽容和善意当成是软弱可欺
* 混学位学生语录
  - 老师, 什么最容易做又能毕业 → 不想努力
  - 老师, 听师兄师姐们说没有文章也能毕业 → 不想写文章
  - 老师, 来你办公室几次你都不在 → 耍小聪明
  - 老师, 下次我一定注意 → 还有下次
  - 老师, 我最近情绪不好 → 你别逼我


### 如何做研究
* 怎样读书
  - 读大师的书和论文, 你才可能成为大师
  - 读垃圾只能产生垃圾，除非你能变废为宝
  - 以教科书入门, 以专著进阶, 以综述拓展视野, 以期刊跟踪前沿
* 怎样选题
  - 初期不必追求具体, 随着研究推进, 选题会自然聚焦
  - 简单问题易上手但价值有限, 复杂问题有深度但门槛高
  - 一个成功的选题, 往往意味着研究已完成50%甚至更多
* 怎样读文献
  - 泛读: 了解问题和结论, 判断其是否值得细读
  - 精读: 提出问题 → 寻找方法 → 结果验证
  - 反思: 创新在哪里 → 真的创新吗 → 能推广吗
  - 借鉴: 主动学习其行文逻辑与表达风格, 把好句子记录下来
* 常见表达误区
  - 照搬自己不懂的概念, 企图让别人懂 → 那是不可能的
  - 自己创造新概念, 不加解释以为别人也懂 → 打哑谜
  - 将自己不懂得东西, 装作很轻松地表述为显然 → 一点都不显然
  - 看完整篇文章, 不知作者做了什么 → 可能构成剽窃
  - 图表缺乏规范标注 → 只剩艺术价值
  - 同一个符号对应n种意思 → 你猜  
   

### 每周组会
* 分享研究进展, 探讨疑难问题
* 清晰表达自身观点, 理性回应他人质疑
* 锻炼创造性思维, 从不同视角中获得启发
* 提升基础科研技能, 包括幻灯片制作和成果展示


### 本人自述

请确定我们是否合适，务必看完下面的介绍，没有七天无理由退货。



我现在以科研为主，没有横向，因此如果你想做横向的话，我们肯定是不合适的。科研，说白了就是写写论文，搞搞算法。我目前感兴趣的方向是大模型与具身智能，毕竟这个很火，我也在尝试转型，之前一直在做最优化算法与应用，这个过程并不是那么容易。
因此，现阶段主要是做具身智能大模型的压缩和部署，逐渐转向工程领域。我也想拿到横向，但并不是那么容易，请学生理解。45岁之前我还是想专心搞科研，如果你仅仅是想混一个毕业，请不要选择我，因为我可能会有点push学生。我希望学生有足够的自主性，我也不想push，但科研始终要有进展。
如果你想做科研，想读博士，那么我们会很契合。如果你仅仅是想工作，混毕业，那么我们不合适，否则大家都会很痛苦。

对于学生，我秉持算法与应用并重, 学生可依兴趣与规划灵活选题。每人支持1-2次国内学术会议, 并预留8-11月求职窗口期，这是我的承诺。

最后，给大家一句心灵鸡汤：做一个解决问题的人, 而不是解释问题的人。
